#Math Arcade | Math Pixels

Plataforma web que reúne seis videojuegos educativos para practicar matemáticas de forma interactiva.

El proyecto fue desarrollado por estudiantes de tercero de secundaria de la Comunidad de Aprendizaje Nezaldi, durante el ciclo escolar 2026–2027, integrando Computación y Matemáticas.

## Objetivo

Fortalecer el pensamiento lógico, la resolución de problemas y el trabajo colaborativo mediante el diseño y la programación de videojuegos con retos matemáticos.

## Videojuegos

- **Nezaldi FC:** fútbol y desafíos matemáticos.
- **Aldi divisor:** operaciones y retos por niveles.
- **A toda mate:** recorrido por el colegio resolviendo ejercicios.
- **Pacminion:** laberintos, persecuciones y preguntas matemáticas.
- **Mathrix:** figuras geométricas y operaciones.
- **DACA:** aventura cooperativa con retos matemáticos.

## Tecnologías utilizadas

- **Python:** desarrollo inicial de ejercicios y lógica de programación.
- **HTML:** estructura de las páginas.
- **CSS:** diseño y presentación visual.
- **JavaScript:** interacción y funcionamiento de los juegos.
- **Netlify y GitHub Pages:** publicación de la plataforma.
- **GitHub:** almacenamiento y seguimiento del proyecto.

## Proceso de trabajo

Los estudiantes participaron en la creación de ideas, reglas, algoritmos, ejercicios y recursos visuales.

Se trabajaron fundamentos de programación en Python y se adaptó una base web para integrar los videojuegos. El proceso incluyó pruebas, corrección de errores y ajustes en la experiencia de juego.

También se utilizaron herramientas de inteligencia artificial como apoyo para revisar errores y crear recursos gráficos, con acompañamiento docente.

## Cómo jugar

Puedes acceder a la plataforma desde:

https://matharcademathpixels.netlify.app/

También puedes descargar este repositorio, extraer sus archivos y abrir `index.html` en un navegador.

Conserva la estructura de carpetas para que las imágenes, los sonidos y los juegos funcionen correctamente.

## Organización del proyecto

- `index.html`: página principal.
- `assets/`: recursos compartidos de la plataforma.
- `juegos/`: archivos de los seis videojuegos.
